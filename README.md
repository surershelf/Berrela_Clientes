# Berrela_Clientes

### App que fiz para a empresa Berrela Empreendimentos.

A empresa se encontrava com problemas em sua gestão, então organizamos um app onde eles consigam fazer o cadastro dos clientes, gerenciar o pagamento e gerar relatórios mensais e ainda enviar mensagens autómaticas a seus clientes, os lembrando de seu dia de pagamento.
